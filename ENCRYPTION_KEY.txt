NHL Hockey - HTML5 Build
========================

Build date: 2026-09-14
Godot version: 4.6.3-stable
Export mode: Web (HTML5) release

Script protection:
- Script export mode: 1 (compiled bytecode / binary tokens)
- Scripts compiled to .gdc bytecode — no GDScript source code in the .pck
- Not decompilable to original source code
- No encryption key needed (mode 1 uses compiled tokens, not AES encryption)

File chunking:
- index.wasm was 35.95MB, split into 2 chunks under 20MB:
  - index.wasm.chunk0 (19.00MB / 19,922,944 bytes)
  - index.wasm.chunk1 (16.95MB / 17,777,722 bytes)
- index.html preloads chunks via fetch, reassembles into a Blob URL,
  and patches findWasmBinary() in index.js to use the Blob URL

To serve:
  Any web server will work, e.g.:
  cd html5_build && python3 -m http.server 8080
  Then open http://localhost:8080/index.html

Note: Cross-Origin Isolation headers are disabled (ensureCrossOriginIsolationHeaders=false)
since this is a nothreads build and doesn't need SharedArrayBuffer.
